## ✨ Features

###  Dual Display Modes
- **RESIZE Mode**: Window with resize handle
- **TITLE Mode**: Window with title bar only

### Custom Background
- Customizable background image with transparency
- Adjustable opacity and color settings

###  Session Management
- Unix domain socket multiplexing
- Persistent terminal sessions
- Detach/Attach functionality

### Advanced Keyboard Shortcuts
- Split panes horizontally/vertically
- Navigate between panes
- Adjust pane sizes
- Session management shortcuts

###  Visual Customization
- Custom fonts and colors
- Padding and margins control
- Disable Wayland for better compatibility
